# Coffin Bay Groundwater Intelligence

Run:
```bash
pip install -r requirements.txt
streamlit run app.py
```

The dashboard contains Overview, Piezometric Map, Model Drivers, Well Explorer, Diagnostics and Scenario Lab.

This is synthetic proof-of-concept data only. For the real Coffin Bay study, replace it with validated groundwater levels, DEM, DEA Coastlines/coast distance, geology, WOfS/surface-water information, NDVI and climate predictors.
